# Проблема и вызовы

- **Спрос растёт на 290% (×3.9)**: 100 т (2035) → 390 т (2040); критический 80 → 250 т (`data/demand.csv`). Стресс: ×1.15 с 2038 → 448.5 т в 2040
- **Сервис**: SL_total ≥ 0.97, SL_critical ≥ 0.99; резерв 45 дней; потолок потерь ≤ 2% в стрессе с 2038
- **Контракты**: take-or-pay 70% у канала A; резервирование мощности оплачивается (0.45 млн/(т·год) у A)
- **Lead times**: A — 12 мес, B — 4 мес, C — 18–24 мес, E — 42 дня → реакция на шок возможна только с лагом
- **CAPEX-лимиты**: ≤ 1 800 млн до 2037, ≤ 2 800 млн до 2040
- **Неопределённость**: цены ±, доля поставки ISRU 0.55/0.75 в стрессе, события команды (MMOD, задержки, тарифы)

# Пользовательский сценарий оператора (UI, Streamlit)

Путь эксперта без разработчика (`docs/ИНСТРУКЦИЯ.md`):

1. `python -m streamlit run app/main.py` → статус «Расчётное ядро доступно»
2. **«Загрузить FINAL BASE»** → обзор: спрос, поставки, запас, SL, расходы
3. **«Ограничения»** → полный реестр проверок: ВЫПОЛНЕНО / НАРУШЕНО / ИНФОРМАЦИЯ, для нарушения — правило, период, факт, лимит, превышение, причина на русском
4. **«План и контракты»** → изменить заказ/резерв/инвестицию → «Применить изменения»
5. Переключить **BASE ↔ MANDATORY_STRESS** → «Пересчитать» → сравнение сценариев
6. **«Сохранение»** → сохранить план в `results/plans/`, повторное открытие восстанавливает план и договоры
7. **Экспорт CSV/XLSX** → 7 таблиц; числа UI = числа экспорта = числа `results/`

<div class="small">

Источник: `app/main.py`, `docs/ИНСТРУКЦИЯ.md`; тесты UI — `tests/test_ui_wave2.py`

</div>

# Стейкхолдеры и адаптивность

**8 сторон** (`docs/note/05_stakeholders.md`): оператор (несёт TOP 824.6 млн в 2040, резервы 549.0 млн, адаптацию +1 537.1 млн PV в стрессе) · критические потребители (SL_critical = 1.000 в обоих сценариях — приоритет аллокации) · коммерческие (без адаптации весь дефицит 130.7 т лёг бы на них) · поставщики A–E · финансирующая сторона (CAPEX 1 430 / 1 800, headroom 370 защищает от R07)

**Гео-тариф A +20% — кто что несёт:** заказчик +337.9 млн PV; провайдер A +471.2 млн выручки (порог переключения A→B: k > 1.44 — вне диапазона [1.15, 1.40])

**Адаптивность:** реакция только с лагом 4 мес (канал B): для событий 2038-01 решение не позднее 2037-08, заказ до 2037-09. Предел компенсации — headroom B ≈ 66–100 т/год. Ex-ante меры в плане: резерв B 110 т/год (16.5 млн/год), ZBO, буфер +7 т, headroom CAPEX 370 млн.
