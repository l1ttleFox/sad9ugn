# Топливный космоконтур 2035 — решение кейса КосмоХакатон 2026

Decision-support система планирования снабжения орбитального топливного узла на 2035–2040.

**Статус: в разработке.** Разработка ведётся несколькими ИИ-агентами параллельно — см. `ai_workstreams/README.md`.

Финальный README с порядком установки, запуска и проверки будет собран WP6 после интеграции всех пакетов работ.

## Структура

```
src/engine/        — расчётное ядро (баланс, финансы, ограничения, экспорт)
app/               — рабочее место оператора (Streamlit)
data/              — CASE_INPUT организатора (неизменяемо) + схемы
configs/           — сценарии BASE / MANDATORY_STRESS / TEAM_*
tests/             — контрольные векторы V01–V10, интеграционные тесты
results/           — сохранённые планы, выгрузки, сравнение сценариев, риски
docs/              — управленческая записка, правила расчёта, источники
presentation/      — слайды защиты
ai_workstreams/    — контракты и промпты параллельной ИИ-разработки
```
