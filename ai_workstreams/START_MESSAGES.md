# Стартовые сообщения для ИИ-исполнителей (волна 1, запуск параллельно)

Копируйте соответствующий блок ПЕРВОЫМ сообщением в новую сессию модели на каждом устройстве. Всё детальное задание модель прочитает сама из репозитория — стартовое сообщение задаёт только точку входа, правила и формат завершения.

Общее правило для всех: после push сессия ЗАВЕРШАЕТСЯ — следующую волну запускает оркестратор после проверки отчёта.

## После завершения волны 1 (все 5 устройств)

Оркестратор (главная сессия) проверяет отчёты и ветки, затем запускает волну 2:
- WP1 → prompt_wave2.md (финансы) — на том же устройстве/модели или новой сессии;
- остальные WP2–WP5 волны 2 стартуют ТОЛЬКО после приёмки WP1-волны3.

Стартовые сообщения для волн 2+ — те же по структуре: клонировать → checkout ветки → прочитать prompt_waveK.md → выполнить → REPORT → push. Детальное задание всегда в prompt-файле.
