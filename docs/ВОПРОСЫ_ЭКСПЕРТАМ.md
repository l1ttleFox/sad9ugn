# Реестр вопросов к экспертам — кейс «Топливный космоконтур 2035»

Статус: НАКОПЛЕНИЕ (встреча запланирована, ~10 минут на тему).
Правило: вопрос добавляется, только если ответ МЕНЯЕТ наши расчёты/стратегию.
Формат ответа эксперта: «да/нет + 1–2 предложения» или «на усмотрение команды, но…».

## Адресаты

- **[ПОСТ]** — эксперт-постановщик кейса (АНО «КЭП», автор кейса 2): трактовка правил, CASE_INPUT, что ждёт жюри, границы кастомизации.
- **[ЛОГ]** — эксперт по космической логистике/криогенике: физика хранения, орбитальные риски, практика снабжения.
- **[ЭКОН]** — эксперт по экономике/инвестициям: ставки, take-or-pay, опционы, финансирование инфраструктуры.
