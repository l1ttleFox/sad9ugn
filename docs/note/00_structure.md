## Сквозные правила записки

1. **Никаких выдуманных чисел.** В записке только: (а) CASE_INPUT из `data/*.csv`, `configs/*.yaml`; (б) результаты формул `docs/CALCULATION_RULES.md` на этих данных; (в) значения из результатов WP2/WP3 (`results/`), каждое трассируется (таблица трассировки — REPORT_wave2 WP5).
2. **Каждое допущение** ссылается на ID реестра TEAM_ASSUMPTION (TA-01…TA-10, `ai_workstreams/00_contracts/units_and_conventions.md` §12). TA-10 («целевой запас 60 дней») утверждён оркестратором (D2.1/D6) ТОЛЬКО для исследовательской стратегии S21; в финальном плане действует политика «45 дней + буфер 7 т» (TD-01).
3. **Атрибуция источников** — строго по `03_methods_evidence_map.md`; в частности: пороговые политики dual sourcing — Federgruen, Liu, Lu (2022); robust-планирование — Han et al. (2023). Каждая ссылка с полным именем.
4. **Числа записки = числа results/ = числа UI** (критерий 5 оценки). Сверка выполнена волной 2; при расхождении источников числа НЕ усредняются — расхождение фиксируется в REPORT (см. REPORT_wave2 WP5, раздел «Расхождения»).

## Раздел 5 «Сравнение стратегий» — итог (полный текст: `09_strategy_comparison.md`)

Метод: двухэтапный скрининг — этап 1: годовые агрегаты всех 25 стратегий × BASE/STRESS (отсев только с числовой причиной); этап 2: детальный прогон топ-5 из разных семейств на ядре + MCDA с раскрытыми весами и swing-проверкой. Единая база: одни CASE_INPUT, r = 10%, t0 = 2035 (TA-06), конвенции lead time TA-02/03/04, политика TD-01.

Итог: финальная стратегия — **S10 «ISRU base»** (A 100/140/190… + B 110 + D 120 с 2038 + ZBO с 2036-07): PV BASE 9961.31 / STRESS 11498.45 млн у.е. (ядро), 0 hard-нарушений в обоих сценариях, SL = 1.000/1.000 все годы, дефицит 0, CAPEX headroom 370 млн, MCDA 0.9700 (1-е место; лидер во всех трёх swing-наборах). Альтернатива S25 (staged gates) дешевле в BASE на 13.31 млн PV (0.13%), но дороже в STRESS на 850.28 млн PV и имеет headroom 280 против 370. Ответы Q1–Q8 (опцион Earth-New, ZBO, профиль A, порог ISRU, цена робастности, мощность 2040, контрактный резерв, headroom) — §9.7. Ценность опциона C: право не платить 270 млн ≈ 203 млн PV → выгоден при P(ISRU-недобор) > 44%; в BASE не окупается ни при каком exercise.

## Раздел 6 «Стресс-тесты и риски» — итог (полный текст: `10_stress_results.md`, `11_risk_results.md`)

MANDATORY_STRESS (CASE_INPUT): спрос ×1.15 с 2038; цены A/B ×1.25 в 2038–2039; доли ISRU 0.55/0.75 (один раз, без reliability — подтверждено 0.550000/0.750000); потолок потерь ≤2% с 2038. Поведение плана: единая стратегия S10, два операционных плана (адаптация заказов TD-01 под профиль сценария). Результат адаптированного FINAL_STRESS: SL = 1.000/1.000, дефицит 0, 0 нарушений, PV +1537.14 млн к BASE (+15.4%); тот же стресс на неадаптированном плане: дефицит 130.7 т, SL_t до 0.849, 5 нарушений (честный ориентир цены адаптации: +1008.7 млн PV). Декомпозиция: дефицит — спрос ×1.15 (+86.4 т) и недопоставка D; деньги — цены ×1.25 (+599.0 млн PV). Reverse-пороги: резерв 45 дн. ломается при спросе ≥×1.02 и доле D ≤0.92; сервис — при спросе ≥×1.05 и доле D ≤0.40; цена A физической границы не имеет (до ×3.00). Grid P04: BASE-план исполним в 11/1331 узлах, стресс-план — в 33/1331. Топ-3 рисков: R02 ISRU-delay (дефицит 13.2 т, 15 нарушений; мера-перезаказ +529.9 млн → остаток 0), R08 срез мощности A (15 нарушений; мера +310.2 млн → остаток 0), R10 гео-тариф (+337.9 млн PV, физика цела).
