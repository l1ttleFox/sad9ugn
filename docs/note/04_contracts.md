# 4. Контрактно-финансовая архитектура

Все параметры каналов ниже — CASE_INPUT (`data/supply_sources.csv`, `data/investment_options.csv`); формулы платежей — `docs/CALCULATION_RULES.md` §5–§6 (цитируются в `01_architecture.md`, блок 6). Контрагенты условные (учебный кейс не задаёт реальных юрлиц). Объём и сроки резервирования по каждому каналу в финальном плане — `[[WP2:final_strategy]]` (волна 2).

## 4.1 Контрактная рамка по каналам

### Канал A — Earth-Core (базовый долгосрочный)

| Параметр | Значение / правило |
|---|---|
| Контрагент | условный «поставщик Earth-Core» (долгосрочный Earth-to-orbit канал) |
| Мощность | 190 т/год (hard: reserved ≤ capacity) |
| Цена | 6.2 млн у.е./т, variable; в MANDATORY_STRESS ×1.25 в 2038–2039 |
| Резервирование | ставка 0.45 млн у.е. за (т/год); `ReservationPayment = reservation_rate * annual_reserved_capacity * period_fraction`, неполный год — prorata |
| Take-or-pay | 70% зарезервированного годового объёма: `Q_pay = max(Q_order, 0.70 * Q_reserved_period)`; TOP уже внутри max(), вторым платежом не добавляется; контрольный период — календарный год |
| Lead time | 12 месяцев (TA-04: заказ в месяце M → поставка M+12) |
| Ответственность поставщика | своевременная поставка заказанных доступных объёмов по плану (BASE детерминирован, reliability 0.96 — только риск-блок WP3, не BASE-множитель) |
| Правило пересмотра | цена и мощность — CASE_INPUT, пересмотру командой не подлежат; объём заказа и резерв — TEAM_DECISION, пересматриваются на инвестиционных воротах (§4.3) |
| Профиль резервирования в финальном плане | `[[WP2:Q3_A_reservation_profile]]` (цена TOP-сжигания профилей S17/S18/S19); переплата по годам — `[[WP2:TOP_burn_final]]` |

Экономический смысл TOP-контракта: дешёвая тонна (6.2 против 8.9 у B) оплачивается обязательством выбрать ≥70% резерва — в ранние годы низкого спроса (100–140 т в 2035–2036) агрессивный резерв A сжигает деньги; класс trade-off поддерживается Han et al. (2023) (стоимость гибкого второго источника) и Federgruen, Liu, Lu (2022) (пороговые политики dual sourcing).

### Канал B — Earth-Flex (гибкий, без обязательств)

| Параметр | Значение / правило |
|---|---|
| Мощность / цена | 110 т/год; 8.9 млн у.е./т; в MANDATORY_STRESS ×1.25 в 2038–2039 |
| Резервирование | 0.15 млн у.е. за (т/год), необязательно |
| Take-or-pay | 0% — контракт «бери сколько нужно» (spot-гибкость) |
| Lead time | 4 месяца — инструмент закрытия пиков и реакции на сбои |
| Роль | «второй источник» dual sourcing: покрывает разрывы A и рост спроса; reliability 0.985 — только риск-блок |

### Канал C — Earth-New (реальный опцион)

| Параметр | Значение / правило |
|---|---|
| Мощность / цена | 130 т/год; 7.1 млн у.е./т |
| Резервирование / TOP | 0.30 млн у.е. за (т/год); TOP 50% **после ввода** |
| Опцион | buy_option = 90 млн (когда угодно до exercise); exercise_option = 270 млн; **90 + 270 = 360 total**, третьего платежа нет (CR §12) |
| Lead time | 18–24 месяца после exercise; контрольная политика — 24 мес (TA-02), чувствительность 18 мес — TEAM-сценарий |
| Reliability | 0.88 первый год эксплуатации, 0.94 далее — только риск-блок |

**Трактовка как реального опциона** (по классу «опционы и гейты в мегапроектах», Tanaka 2014 — см. оговорку в `03_methods_evidence_map.md` §3.3): плата 90 млн покупает **право, но не обязательство** добавить 130 т/год за 270 млн. Ценность опциона = разница стоимости адаптивной ветви (exercise при неблагоприятном исходе / отказ при благоприятном) против неадаптивных альтернатив, за вычетом платы 90: `[[WP2:option_value_C]]`; окупаемость и сравнение early/late/option-hold — `[[WP2:Q1_earth_new_payback]]` (стратегии S07/S14/S15/S16).

### Канал D — Lunar-ISRU (стратегическая инвестиция)

| Параметр | Значение / правило |
|---|---|
| Мощность / цена | 120 т/год; 3.0 млн у.е./т — самый дешёвый ресурс после ввода |
| CAPEX | 1250 млн, платёж **до 2038-01** (дедлайн 2037-12); fixed OPEX +70 млн/год с 2038 |
| Lead time | 1–2 месяца после ввода; политика команды — 2 месяца (units_and_conventions §2) |
| Reliability | 0.78 / 0.90 / 0.93 в 2038–2040 — только риск-блок; в MANDATORY_STRESS фактические доли 0.55 (2038) / 0.75 (2039) применяются к плану и НЕ умножаются на reliability повторно |
| Резервирование / TOP | 0 — нет договорных минимумов |

Порог выгодности (при каком годовом отборе D замещение через B/E дороже: 3.0 против 8.9/13.8 млн/т) — `[[WP2:Q4_isru_threshold]]`. Обоснованность сравнения «Земля vs Луна» на единой экономической базе с учётом неопределённости — по Sommariva et al. (2023); их вывод в пользу лунного топлива не переносится как готовый ответ кейса.

### Канал E — Emergency (аварийный, не базовый)

| Параметр | Значение / правило |
|---|---|
| Мощность / цена | 80 т/год; 13.8 млн у.е./т — самая дорогая тонна |
| Резервирование | 0.35 млн у.е. за (т/год), обязательно по условиям канала |
| Lead time | **6 недель = 42 дня** (единица CASE_INPUT — week; в месячной сетке — поставка в следующем месяце, TA-03) |
| Hard-ограничение | EMERGENCY_BASE_STREAK ≤ 2 лет подряд (рабочая трактовка «базовости»: отбор > 40% годового served — TA-09) |
| Роль в резерве 45 дней | контрактный эквивалент засчитывается только при доказательстве покрытия периода ожидания 42 дня: объём ≥ спрос за 42 дня + покрытие до прибытия (units_and_conventions §6, поле `emergency_contract`) |

Годовая мощность 80 т/год сама по себе не означает немедленной доступности 80 т в узле (STARTER_README §14); штраф или компенсация не создают физический ресурс (CR §14). Сравнение «контрактный E-резерв против физического запаса» — `[[WP2:Q7_contractual_reserve]]` (S22 vs S21).

## 4.2 Распределение рисков «оператор — поставщик»

| Риск | Несёт оператор | Несёт поставщик | Механизм контракта |
|---|---|---|---|
| Недоотбор (рыночный риск спроса) | да — платит TOP минимум (A: 70%, C: 50% после ввода) | — | take-or-pay |
| Недоступность мощности в пик | да — платит reservation даже без отбора (A, B, C, E) | держит мощность готовой | capacity reservation |
| Сбой поставки | частично (последствия для SL и запаса) | в рамках reliability-профиля (интерпретация — риск-блок WP3) | reliability metadata + physical reserve + Emergency |
| Ценовой шок | да (в MANDATORY_STRESS ×1.25 для A/B) | — | фиксированные цены CASE_INPUT; хеджирование не задано |
| Переполнение/дефицит хранения | да | — | STORAGE_OVERFLOW / shortage как нарушения с периодом и excess |
| Перерасход CAPEX | да | — | лимиты 1800/2800; риск-оценка перерасхода ISRU — `[[WP3:risk_isru_overrun]]` |

## 4.3 Инвестиционные ворота (decision gates)

Структура гейтов — по классу «stage-gate + опционы» (Tanaka 2014, конспект оркестратора, см. оговорку §3.3); каждая точка решения привязана к наблюдаемой информации, а не к «правильной дате» (репозиторий организатора дату не публикует).

| Гейт | Срок | Решение | Условие продолжения (заготовка; количественные пороги — волна 2) |
|---|---|---|---|
| **G1** | 2035 | старт A/B-контрактов; покупать ли опцион C (90 млн)? | CAPEX through-2037 с запасом ≤ 1800; стоимость option-hold против раннего exercise — `[[WP2:Q1_earth_new_payback]]` |
| **G2** | 2036–2037 | финансирование ZBO (180 млн, доступно с 2036-01) | обязательно для потолка потерь ≤2% в стрессе с 2038 — доказательство `[[WP2:Q2_zbo_proof]]` (S11 vs S10) |
| **G3** | до 2037-12 | финансирование ISRU (1250 млн) | headroom CAPEX_2037 после 1250 (+180 ZBO, +90 опцион = 1520; с exercise C 1790 ≤ 1800); порог выгодности D — `[[WP2:Q4_isru_threshold]]` |
| **G4** | 2038 | exercise опциона C (270 млн) — по факту ISRU-2038 | количественный триггер (пример из промпта WP2 для S16/S25: «exercise если факт ISRU 2038 < порога», в стрессе факт 55%) — `[[WP2:gate_G4_trigger_value]]` |

CAPEX-профиль по годам финального плана и привязка платежей к лимитам — `[[WP2:capex_profile_final]]`; запас по лимитам — `[[WP2:Q8_capex_headroom]]`.

## 4.4 Структура финансирования (TEAM_ASSUMPTION-опция)

Кейс не задаёт выручку и стоимость срыва миссии (CR §8), поэтому финансовая модель — «сравнение расходов на единой ставке». Как исследовательское расширение допускается описать проектную упаковку:

- **ГЧП/проектное финансирование** крупных опций (ISRU 1250, Earth-New 360) — по образцу сравнения архитектур у Sommariva et al. (2023) (высокая неопределённость investment/OPEX → стадийность и опционность) и stage-gate-подходу Tanaka (2014, конспект оркестратора);
- ставка дисконтирования 10% реальная, t0=2035 (TA-06), все альтернативы на одной ставке;
- статус: **TEAM_ASSUMPTION, не условие кейса**; никаких чисел структуры капитала не приводится, пока их нет в результатах WP2.

## 4.5 Правила пересмотра контрактов

1. Изменение параметров CASE_INPUT (цены, мощности, тарифы, лимиты) запрещено (CASE_RULES §4) — «пересмотр» возможен только как отдельный TEAM_* research-сценарий с явным mapping на input (STRESS_PROTOCOL).
2. Объёмы заказа, резервирования и момент инвестиций пересматриваются на гейтах G1–G4 (§4.3); каждое решение ветвления явно (для адаптивных S16/S25 — пара ветвей с правилом).
3. Нарушение ограничения не «чинится» задним числом: показывается как Violation (rule_id, период, факт, лимит, excess), план диагностируется (CASE_RULES §8).
