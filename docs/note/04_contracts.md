# 4. Контрактно-финансовая архитектура

Все параметры каналов ниже — CASE_INPUT (`data/supply_sources.csv`, `data/investment_options.csv`); формулы платежей — `docs/CALCULATION_RULES.md` §5–§6 (цитируются в `01_architecture.md`, блок 6). Контрагенты условные (учебный кейс не задаёт реальных юрлиц). Объём и сроки резервирования в финальном плане (стратегия **S10 «ISRU base»**, `results/plans/FINAL_BASE.json`): A — 100/140/190/190/190/190 т/год в 2035–2040; B — 110 т/год все 6 лет; D — 120 т/год в 2038–2040 (бесплатное резервирование); C и E не резервируются (не используются). Инвестиции: LUNAR_ISRU 1250 млн и ZBO 180 млн — платёж 2036-06.

## 4.1 Контрактная рамка по каналам

### Канал A — Earth-Core (базовый долгосрочный)

| Параметр | Значение / правило |
|---|---|
| Контрагент | условный «поставщик Earth-Core» (долгосрочный Earth-to-orbit канал) |
| Мощность | 190 т/год (hard: reserved ≤ capacity) |
| Цена | 6.2 млн у.е./т, variable; в MANDATORY_STRESS ×1.25 в 2038–2039 |
| Резервирование | ставка 0.45 млн у.е. за (т/год); `ReservationPayment = reservation_rate * annual_reserved_capacity * period_fraction`, неполный год — prorata |
| Take-or-pay | 70% зарезервированного годового объёма: `Q_pay = max(Q_order, 0.70 * Q_reserved_period)`; TOP уже внутри max(), вторым платежом не добавляется; контрольный период — календарный год |
| Lead time | 12 месяцев (TA-04: заказ в месяце M → поставка M+12) |
| Ответственность поставщика | своевременная поставка заказанных доступных объёмов по плану (BASE детерминирован, reliability 0.96 — только риск-блок WP3, не BASE-множитель) |
| Правило пересмотра | цена и мощность — CASE_INPUT, пересмотру командой не подлежат; объём заказа и резерв — TEAM_DECISION, пересматриваются на инвестиционных воротах (§4.3) |
| Профиль резервирования в финальном плане | 100→140→190 т/год (растёт вместе со спросом). Цена TOP-сжигания альтернативных профилей (Q3, суммарная TOP-переплата 2035–2040, BASE): S17 (A=190 с 2035) — 2304.8 млн у.е.; S18 (demand-tracking) — 1898.8 млн; S19 (A-minimal) — 1643.8 млн; цена агрессивного A в 2035–2036: S17−S18 = 258.4 млн, S17−S19 = 339.7 млн. Переплата FINAL-плана по годам (`take_or_pay_extra_mln`, `results/exports/FINAL_BASE/financial_breakdown.csv`): 2035–2039 — 0; **2040 — 824.6 млн** (резерв 190 т при отборе ~60 т после ввода D) — предмет пересмотра на воротах G5 (§12.3) |

Экономический смысл TOP-контракта: дешёвая тонна (6.2 против 8.9 у B) оплачивается обязательством выбрать ≥70% резерва — в ранние годы низкого спроса (100–140 т в 2035–2036) агрессивный резерв A сжигает деньги; класс trade-off поддерживается Han et al. (2023) (стоимость гибкого второго источника) и Federgruen, Liu, Lu (2022) (пороговые политики dual sourcing).

### Канал C — Earth-New (реальный опцион)

| Параметр | Значение / правило |
|---|---|
| Мощность / цена | 130 т/год; 7.1 млн у.е./т |
| Резервирование / TOP | 0.30 млн у.е. за (т/год); TOP 50% **после ввода** |
| Опцион | buy_option = 90 млн (когда угодно до exercise); exercise_option = 270 млн; **90 + 270 = 360 total**, третьего платежа нет (CR §12) |
| Lead time | 18–24 месяца после exercise; контрольная политика — 24 мес (TA-02), чувствительность 18 мес — TEAM-сценарий |
| Reliability | 0.88 первый год эксплуатации, 0.94 далее — только риск-блок |

**Трактовка как реального опциона** (по классу «опционы и гейты в мегапроектах», Tanaka 2014 — см. оговорку в `03_methods_evidence_map.md` §3.3): плата 90 млн покупает **право, но не обязательство** добавить 130 т/год за 270 млн. Ценность опциона = разница стоимости адаптивной ветви (exercise при неблагоприятном исходе / отказ при благоприятном) против неадаптивных альтернатив, за вычетом платы 90. Расчёт (Q1, §9.7–9.8): право не платить 270 млн при решении в 2038 ≈ 270/1.1³ ≈ 203 млн PV — опцион выгоден при P(стресс-ISRU-недобор) > 44% (вероятность не заявляется — сценарный подход). В BASE опцион НЕ окупается ни при каком exercise: полный пакет +2013.6 млн PV к S10; поздний exercise (S15) дешевле раннего (S14) на 822.5 млн PV; option-hold (S16) стоит +90.0 млн PV BASE и +953.6 млн STRESS к S10 — опцион с lead time 24 мес не закрывает главный стресс-риск 2038–2039 (C доступен лишь с 2040-01). Экономически оправдан только как страховка мощности 2041+ при спросе > 420 т. **В финальном плане S10 опцион C не покупается** (решение G1, §12.3).

### Канал D — Lunar-ISRU (стратегическая инвестиция)

| Параметр | Значение / правило |
|---|---|
| Мощность / цена | 120 т/год; 3.0 млн у.е./т — самый дешёвый ресурс после ввода |
| CAPEX | 1250 млн, платёж **до 2038-01** (дедлайн 2037-12); fixed OPEX +70 млн/год с 2038 |
| Lead time | 1–2 месяца после ввода; политика команды — 2 месяца (units_and_conventions §2) |
| Reliability | 0.78 / 0.90 / 0.93 в 2038–2040 — только риск-блок; в MANDATORY_STRESS фактические доли 0.55 (2038) / 0.75 (2039) применяются к плану и НЕ умножаются на reliability повторно |
| Резервирование / TOP | 0 — нет договорных минимумов |

Порог выгодности (Q4, при каком годовом отборе D замещение через B/E дороже: 3.0 против 8.9/13.8 млн/т): PV издержек D = 1250/1.1 + 70×(1.1⁻³+1.1⁻⁴+1.1⁻⁵) = 1136.4 + 143.9 = **1280.2 млн у.е.**; экономия B→D = 5.9 млн/т → порог окупаемости **217 т** суммарного отбора за 2038–2040, т.е. **≥ 72 т/год**. Факт BASE: 223.7 т > 217 → окупается (экономия 1320.0 > 1280.2). В STRESS фактические поставки D = 178.9 т < 217 — на грани окупаемости (недобор замещается B по 11.125 млн/т, +364 млн номинал); решение держится на продлении работы D после 2040 (вне горизонта CASE_INPUT — исследовательская оговорка). Обоснованность сравнения «Земля vs Луна» на единой экономической базе с учётом неопределённости — по Sommariva et al. (2023); их вывод в пользу лунного топлива не переносится как готовый ответ кейса.

### Канал E — Emergency (аварийный, не базовый)

| Параметр | Значение / правило |
|---|---|
| Мощность / цена | 80 т/год; 13.8 млн у.е./т — самая дорогая тонна |
| Резервирование | 0.35 млн у.е. за (т/год), обязательно по условиям канала |
| Lead time | **6 недель = 42 дня** (единица CASE_INPUT — week; в месячной сетке — поставка в следующем месяце, TA-03) |
| Hard-ограничение | EMERGENCY_BASE_STREAK ≤ 2 лет подряд (рабочая трактовка «базовости»: отбор > 40% годового served — TA-09) |
| Роль в резерве 45 дней | контрактный эквивалент засчитывается только при доказательстве покрытия периода ожидания 42 дня: объём ≥ спрос за 42 дня + покрытие до прибытия (units_and_conventions §6, поле `emergency_contract`) |

Годовая мощность 80 т/год сама по себе не означает немедленной доступности 80 т в узле (STARTER_README §14); штраф или компенсация не создают физический ресурс (CR §14). Сравнение «контрактный E-резерв против физического запаса» (Q7, S22 vs S21): E доставляет за период ожидания 42 дня лишь 80×42/365 = **9.21 т** при спросе за 42 дня от 11.51 т (2035) до 44.88 т (2040 BASE) и 51.6 т (STRESS 2040) → RESERVE_45D нарушен все 6 лет в обоих сценариях; S21 (физический запас) проходит все проверки и на 73.6 млн PV дешевле в BASE. **Вывод: физический запас дешевле И доказуемее; контрактный E-резерв не является эквивалентом 45 дней ни в одном году** — в FINAL принят физический резерв (reserve_mode: physical).

|---|---|---|---|

## 4.3 Инвестиционные ворота (decision gates)

Структура гейтов — по классу «stage-gate + опционы» (Tanaka 2014, Procedia SBS 119:65–74, DOI `10.1016/j.sbspro.2014.03.010` — сверено по первоисточнику; оговорка о границах применения §3.3: количественные условия ворот — расчёт команды, а не положения публикации); каждая точка решения привязана к наблюдаемой информации, а не к «правильной дате» (репозиторий организатора дату не публикует). Полные количественные условия G1–G5 — `12_roadmap_budget.md` §12.3.

| Гейт | Срок | Решение | Количественное условие продолжения / остановки |
|---|---|---|---|
| **G1** | 2035 | старт A/B-контрактов; покупать ли опцион C (90 млн)? | CAPEX through-2037 с запасом ≤ 1800 (факт 1430, headroom 370). Опцион C НЕ покупать: option-hold стоит +90.0 млн PV BASE и +953.6 млн PV STRESS к S10; C с lead time 24 мес доступен лишь с 2040-01 и не закрывает стресс 2038–2039 (Q1, §9.7). Покупка оправдана только как страховка спроса 2041+ > 420 т и при P(ISRU-недобор) > 44% |
| **G2** | 2036 (платёж 2036-06) | финансирование ZBO (180 млн, доступно с 2036-01, ввод 2036-07) | ОБЯЗАТЕЛЬНО: без ZBO потолок потерь ≤2% нарушен — S11 в STRESS 0.045 > 0.02 в 2038–2040, с ZBO (S10) 0.012 ≤ 0.02 (Q2). Цена ZBO +69.7 млн PV BASE. Остановка = отказ от стресс-устойчивости |
| **G3** | до 2037-12 (выбран 2036-06) | финансирование ISRU (1250 млн) | Продолжить: порог окупаемости 217 т отбора за 2038–2040 (Q4), плановый факт BASE 223.7 т > 217; headroom CAPEX_2037 после 1250+180 = 1430 → 370 ≤ 1800. Без D стресс-2040 (448.5 т) физически не проходит составом ≤430 т/год (Q6). Остановиться — если прогноз спроса 2040 < 390 т или отбор D < 72 т/год |
| **G4** | 2038-01 | exercise опциона C (270 млн) — по факту ISRU-2038 (для FINAL — мониторинг, опциона нет) | **Триггер (расчётное правило ветвления S16/S25): фактическая доля поставки D-2038 ≤ 0.60 → exercise C** (2038-01; C с 2040-01; резерв 130 т в 2040). В MANDATORY_STRESS факт 0.55 → ветвь exercise (+270 CAPEX в 2038). Факт ≥ 0.60 (BASE = 1.0) → не exercise, 90 млн невозвратны |

CAPEX-профиль финального плана по годам: 2035 — 0; **2036 — 1430 млн** (LUNAR_ISRU 1250 + ZBO 180, платёж 2036-06); 2037–2040 — 0 (таблица и привязка к лимитам — `12_roadmap_budget.md` §12.1–12.2). Запас по лимитам (Q8): headroom CAPEX_2037 = 1800 − 1430 = **370 млн** (у «полного пакета» S14/S15/S17–S24 = 10 млн — хрупкость к перерасходу ISRU R07), CAPEX_2040 = 2800 − 1430 = 1370 млн.

## 4.4 Структура финансирования (TEAM_ASSUMPTION-опция)

Кейс не задаёт выручку и стоимость срыва миссии (CR §8), поэтому финансовая модель — «сравнение расходов на единой ставке». Как исследовательское расширение допускается описать проектную упаковку:

- **ГЧП/проектное финансирование** крупных опций (ISRU 1250, Earth-New 360) — по образцу сравнения архитектур у Sommariva et al. (2023) (высокая неопределённость investment/OPEX → стадийность и опционность) и stage-gate-подходу Tanaka (2014), Procedia SBS 119:65–74, DOI `10.1016/j.sbspro.2014.03.010` (сверено по первоисточнику);
- ставка дисконтирования 10% реальная, t0=2035 (TA-06), все альтернативы на одной ставке;
- статус: **TEAM_ASSUMPTION, не условие кейса**; никаких чисел структуры капитала не приводится, пока их нет в результатах WP2.

## 4.5 Правила пересмотра контрактов

1. Изменение параметров CASE_INPUT (цены, мощности, тарифы, лимиты) запрещено (CASE_RULES §4) — «пересмотр» возможен только как отдельный TEAM_* research-сценарий с явным mapping на input (STRESS_PROTOCOL).
2. Объёмы заказа, резервирования и момент инвестиций пересматриваются на гейтах G1–G4 (§4.3); каждое решение ветвления явно (для адаптивных S16/S25 — пара ветвей с правилом).
3. Нарушение ограничения не «чинится» задним числом: показывается как Violation (rule_id, период, факт, лимит, excess), план диагностируется (CASE_RULES §8).
