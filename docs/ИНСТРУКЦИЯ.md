# Инструкция оператору: топливный космоконтур 2035–2040

## Запуск

В корне репозитория выполните команды:

    python -m pip install -r requirements.txt
    python -m streamlit run app/main.py

Откройте локальный адрес, который покажет Streamlit. В левой панели должны быть видны статус «Расчётное ядро доступно», сценарий, период 2035–2040 и кнопки демонстрационных планов.

## Основной сценарий

1. **Контрольный набор и готовый план.** Приложение читает входные CSV из data/, BASE/STRESS из configs/ и исследовательские TEAM_* из configs/team/ либо резервного каталога WP3. Нажмите слева «Загрузить FINAL BASE / FINAL STRESS». До публикации FINAL автоматически предлагается S10 из WP2; тот же план можно переключать между BASE и STRESS.
2. **Открытие или создание.** В «Сохранении» выберите JSON из results/plans/, загрузите свой файл либо начните с пустого плана. Невалидный JSON не вызывает traceback: интерфейс показывает по-русски конфликтующий параметр и период.
3. **Изменение решений.** В «План и контракты» отредактируйте заказ (т), резервирование (т/год) или инвестицию (действие и дата), затем нажмите «Применить изменения». Здесь же задаются начальный/целевой запас и аварийный контракт. Реестр договоров редактируется отдельно от расчётного плана.
4. **Пересчёт.** В «Сценариях» нажмите «Пересчитать». На «Обзоре» и «Графиках» проверьте спрос, фактические поставки, запас, потери, расходы, дефицит и общий/критический SL. Все объёмы указаны в т, мощности — в т/год, деньги — в млн у.е., SL — в долях или процентах.
5. **Нарушения и сравнение.** В «Ограничениях» есть полный реестр проверок ядра: «ВЫПОЛНЕНО» и «НАРУШЕНО». Для каждого нарушения показаны правило, период, факт, лимит, превышение и русская причина. Переключите BASE ↔ MANDATORY_STRESS и сравните таблицу и годовые дельты.
6. **TEAM и геополитика.** Выберите любой TEAM_* слева — он помечен как исследовательский. Для собственного события в «Сценариях» укажите название, канал, коэффициент цены и годы. После просмотра эффекта нажмите «Восстановить контрольные цены»: BASE возвращается к исходному результату, входные файлы не изменяются.
7. **Сохранение и повторное открытие.** В «Сохранении» задайте plan_id и нажмите «Сохранить в каталог». Ядро пишет results/plans/<plan_id>.json; условия договоров сохраняются рядом в results/plans/<plan_id>_contracts.json. При повторном открытии восстанавливаются и план, и договоры.
8. **Экспорт.** Кнопка CSV выдаёт ZIP с yearly_balance, source_schedule, inventory_trace, financial_breakdown, constraint_checks, risk_register и метаданными. Кнопка XLSX выдаёт книгу с теми же таблицами. Экспорт строится из того же RunResult, который показан на экране.
